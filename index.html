🧾 Costco Multi-Account Dashboard

Receipt files are processed in this browser and are never uploaded to this dashboard. The bookmarklet requests data directly from Costco. Anonymous usage analytics are sent to GoatCounter; they do not include receipt data.

1. Export your Costco data

  1. Drag the Drag to Bookmarks button below to your bookmarks bar.
  2. Sign in at costco.com and click the saved bookmark. A JSON file will download.

2. Load data into the dashboard

  1. Return to this dashboard, click Select JSON files, and choose the downloaded file.
  2. Select additional JSON files too if you want to load more data.
