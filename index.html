How to Use

1. Get the code

  1. Open the GitHub repository.
  2. Click Code, then Download ZIP, and extract it (or run git clone).
  3. Open index.html in any modern browser.

2. Export your Costco data

  1. Drag the Drag to Bookmarks link onto your bookmarks bar.
  2. Log in at costco.com, then click the saved bookmark.
  3. A .json file downloads. If the bookmark is blocked, use Method B in the README.

3. Load it into the dashboard

  1. Click Upload Receipts and select one or more exported files.
  2. Duplicates are merged automatically.
  3. Use the filters to switch between In-Warehouse, Online, Gas Station and Car Wash.
